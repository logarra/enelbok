# Opel Astra J Sedan 3D

2017 model Opel Astra J Sedan (1.6 Ecotec 115 PS, 5 ileri manuel, Edition / Edition Plus) için telefonda açılan, etkileşimli 3D inceleme sayfası.

`index.html` dosyasını bir web sunucusundan aç (`astra.glb` ve `engine.glb` aynı klasörde olmalı; three.js CDN'den yüklenir).

- Gerçek 3D araç modeli; renk seçimi, farlar
- Animasyonlu 4 kapı, bagaj kapağı ve kaput (kaput modelden ayrıldı)
- Kaput altında gerçek Astra J motor bölümü taraması
- İç mekân (tavan kesik), sürücü koltuğu bakışı, manuel vites kolu ve 3 pedal
- Şasi / süspansiyon şeması, röntgen (saydam kasa), patlatılmış görünüm
- Parçaya dokun → bilgi kartı; "Bilgi" → teknik veri ve donanım listesi

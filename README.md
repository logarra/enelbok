# Opel Astra J Sedan 3D

2017 model Opel Astra J Sedan (1.6 Ecotec 115 PS, 5 ileri manuel, Edition / Edition Plus) için telefonda açılan, etkileşimli 3D inceleme sayfası.

`index.html` dosyasını tarayıcıda aç (internet gerekir; three.js CDN'den yüklenir).

- Dış görünüm, renk seçimi, farlar
- Animasyonlu 4 kapı, bagaj kapağı ve kaput
- İç mekân (tavan kesik) ve sürücü koltuğu bakışı
- Motor bölümü (A16XER, şanzıman, akü, radyatör…)
- Şasi / süspansiyon, röntgen (saydam kasa), patlatılmış görünüm
- Parçaya dokun → bilgi kartı; "Bilgi" → teknik veri ve donanım listesi

Model, referans fotoğraflardan prosedürel olarak (kod ile) üretilmiştir.
